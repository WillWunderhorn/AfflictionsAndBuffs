# AfflictionsAndBuffs

This is a mod for **The Long Dark** by Hinterland Studio, Inc.

This mod adds 4 more afflictions and 4 buffs!

## Installation

1. Install MelonLoader
2. Install[AfflictionComponent](https://github.com/TLD-Mods/AfflictionComponent/releases/tag/v1.0.6)
3. Install [ModData](https://github.com/dommrogers/ModData/releases/tag/1.5.5)
4. Install [ModComponent](https://github.com/dommrogers/ModComponent)
5. Download the latest version of `AfflictionsAndBuffs.dll` from the [releases page](https://github.com/WillWunderhorn/AfflictionsAndBuffs/releases/tag/Latest)
6. Move `AfflictionsAndBuffs.dll` into the Mods folder in your TLD install directory
