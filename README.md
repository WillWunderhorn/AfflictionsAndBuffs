# AfflictionsAndBuffs

This is a mod for **The Long Dark** by Hinterland Studio, Inc.

This mod adds 3 more afflictions and 4 buffs!

## Installation

1. Install MelonLoader
2. Download the latest version of `AfflictionsAndBuffs.dll` from the [releases page](https://github.com/WillWunderhorn/AfflictionsAndBuffs/releases/tag/Latest)
3. Move `AfflictionsAndBuffs.dll` into the Mods folder in your TLD install directory
