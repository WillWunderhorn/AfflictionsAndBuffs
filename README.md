# AfflictionsAndBuffs

This is a mod for **The Long Dark** by Hinterland Studio, Inc.

This mod adds 3 more afflictions and 4 buffs!

## Installation

1. Install MelonLoader
2. Install[](https://github.com/TLD-Mods/AfflictionComponent/releases/tag/v1.0.6)
3 Install [](https://github.com/dommrogers/ModData/releases/tag/1.5.5)
4. Download the latest version of `AfflictionsAndBuffs.dll` from the [releases page](https://github.com/WillWunderhorn/AfflictionsAndBuffs/releases/tag/Latest)
5. Move `AfflictionsAndBuffs.dll` into the Mods folder in your TLD install directory
