# AfflictionsAndBuffs

This is a mod for **The Long Dark** by Hinterland Studio, Inc.

This mod adds 3 more afflictions and 4 buffs!

**---------------------
Afflictions:
LulledByTheWind - You've spent a lot of time in the fresh air - if you stay out longer, you might start to feel sleepy.
Starving - You've been starving for quite a while, your body is working itself to the bone
(Secret affliction) - ???
---------------------
Buffs:
BurningHeart - You have added fuel to a strong, warm fire. Its comforting heat still lingers in your heart.
Determination - The weather is clear! You feel much better!
FogsEmbrace - You are surrounded by heavy fog. Wildlife is less aware of your presence.
LittleHeart - ???
---------------------**

## Installation

1. Install MelonLoader
2. Download the latest version of `AfflictionsAndBuffs.dll` from the [releases page](https://github.com/WillWunderhorn/AfflictionsAndBuffs/releases/tag/Latest)
3. Move `AfflictionsAndBuffs.dll` into the Mods folder in your TLD install directory
